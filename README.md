# 🐾 Gemini 桌宠观察窗 (Gemini Pet Observer)

在 `gemini.google.com` 网页端右下角常驻一只 Q 版二次元桌宠，头顶带有一个经典思考气泡，实时显示 **5 小时剩余额度、每周剩余额度、重置倒计时与当前上下文 Token 占用**，并支持无感静默校准与物理果冻 Q 弹互动。

> 💡 **预览截图**：*(在 GitHub 网页端编辑本文件时，直接把运行截图拖到此处即可自动生成预览图)*

## ✨ 核心特性

* **无感自动校准官方额度**：每轮对话生成完毕后，通过同源隐形 `iframe` 静默读取 `/usage` 页面真实消耗并反算剩余百分比，**不弹窗、不抢焦点、不闪烁顶部标签栏**；支持点击思考气泡随时手动校准。
* **多表情智能状态机**：
  * `idle.webp`：日常待机呼吸起伏状态
  * `eat.webp`：Gemini 正在流式输出回复时，自动切换为“啃食 Token”咀嚼摇晃状态
  * `xd.webp` / `grin.webp`：单次回复生成完成或鼠标点击互动时触发对应开心表情
* **果冻 Q 弹互动与卖萌气泡**：
  * **单击小人**：触发果冻弹性形变物理动画，随机切换表情并弹出随机卖萌台词
  * **双击小人**：优雅收起或展开头顶的额度思考气泡
  * **单击额度气泡**：立即触发一次官方真实额度同步
* **零样式污染**：基于 Manifest V3 与 `Shadow DOM` 构建，完全隔离 Gemini 网页原有样式。

## 📦 安装方法（Chrome / Edge）

1. 前往本仓库右侧的 **[Releases](../../releases)** 页面，下载最新的 `gemini-pet-observer-v1.4.0.zip` 并解压到一个固定文件夹（安装后请勿删除该文件夹）。
2. 打开浏览器地址栏，输入 `chrome://extensions/`（Edge 浏览器输入 `edge://extensions/`）。
3. 开启右上角的 **开发者模式（Developer mode）**。
4. 点击左上角的 **加载已解压的扩展程序（Load unpacked）**，选择刚刚解压出来的文件夹。
5. 打开或刷新 [Gemini 网页端](https://gemini.google.com/)，右下角即可看到常驻桌宠。

## 🎨 自定义角色皮肤与台词

* **更换角色立绘**：直接用你喜欢的透明背景 `.webp` 或 `.png` 图片替换插件文件夹中的 `idle.webp`、`eat.webp`、`xd.webp`、`grin.webp`（保持文件名一致），然后在 `chrome://extensions/` 点击插件的刷新图标即可生效。
* **修改卖萌台词**：使用任意文本编辑器打开 `content.js`，搜索 `CUTE_LINES` 数组，自由增删角色台词。
